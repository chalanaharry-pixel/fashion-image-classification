# 👕 Deep Learning Fashion Image Classification

## 📌 Project Overview

This project uses **Deep Learning and Artificial Neural Networks (ANN)** to classify fashion product images into different categories.

The project is designed for a fashion **e-commerce business**, where AI can automatically identify product categories from uploaded images instead of relying completely on manual work.

## 🎯 Objective

The main objective is to:

* Classify fashion product images automatically
* Understand how images are used as Deep Learning input
* Build and train a simple Artificial Neural Network
* Check the model's accuracy
* Predict the category of new fashion images
* Understand the business use of AI

## 🛍️ Product Categories

The model classifies images into **10 categories**:

1. T-shirt/Top
2. Trouser
3. Pullover
4. Dress
5. Coat
6. Sandal
7. Shirt
8. Sneaker
9. Bag
10. Ankle Boot

## 📊 Dataset

The project uses the **Fashion MNIST dataset** provided through TensorFlow/Keras. The dataset contains images of common fashion products and downloads automatically when the notebook is run.

## 🧠 Model Architecture

The project uses a simple neural network:

**Input Image → Flatten → Hidden Layer → Output Layer**

* Input: 28 × 28 image
* Flatten layer: C
